# 《实现领域驱动设计》交互学习手册

这是一份独立的新手册，围绕 Vaughn Vernon 的《实现领域驱动设计》（红皮书）组织，不依赖任何其他项目。

打开 **[HANDBOOK.html](HANDBOOK.html)** 即可使用。样式、内容和交互脚本全部内嵌，学习不需要联网、登录、Node 或后端服务。外部资料链接需要网络。移动整份目录可以保留 Java 源码下载链接；只带走 HTML 也可以正常使用所有浏览器实验。

- 14 章 + 附录 A，保留原书的章节顺序。
- 每章：核心问题、三条判断、深入推演、原创案例、代码片段、误读辨析、设计题、两道自测。
- 5 个交互实验：聚合边界、并发冲突、事件与 CQRS、防腐层、事件重放。
- 全文搜索、26 个术语、深浅主题、手机布局、打印当前章节。
- 已读进度、自测与笔记保存在当前浏览器，可导出 / 合并导入 JSON。
- 独立贯穿案例：企业知识共创平台的双人评审。

## 资料范围

已核对出版社完整目录、公开聚合样章、作者聚合设计文章和部分官方配套代码。**未取得红皮书全书全文，因此本手册是按章组织的原创导学，不是全书逐页精读摘要。** 每章和“资料与范围”页均附参考链接。

英文版的章节标题与起始页用于定位，中文版本的译名及页码可能不同。Java 21、Outbox / Inbox 等演练是现代实现选择和工程补充；所有案例、问题、讲解及示例代码均为新写，没有复制书中文字、图表或配套实现。

## 可运行的 Java 模型

需要 **JDK 21**，零第三方依赖，在此目录运行：

```sh
java examples/ReviewExample.java
```

macOS 安装了多个 JDK 时，可显式使用 JDK 21 的 `bin/java`。示例包含聚合、值对象、内存版本仓储和 22 项检查。范围是纯领域行为与内存并发语义，**不实现数据库事务、认证授权、消息中间件或 Spring Boot 服务**。章节中其他代码片段已分别标注为结构示意，不应当作可直接部署的项目。

## 文件结构与修改

| 文件 | 用途 |
| --- | --- |
| HANDBOOK.html | 可离线打开的完整交互手册 |
| HANDBOOK.md | 章节内容的文字版，含练习答案与来源 |
| examples/ReviewExample.java | 可运行的原创 Java 模型 |
| src/content.js | 全部章节、自测、术语与来源 |
| src/app.js | 阅读界面与五个实验的状态逻辑 |
| src/style.css | 响应式与打印样式 |
| src/shell.html | 页面外壳 |
| build.mjs | 生成 HTML 与 Markdown，不需要安装包 |
| qa/ | 内容清单与验收记录 |

修改源文件后，用 Node.js 运行：

```sh
node build.mjs
```

## 学习记录

数据仅存于当前浏览器的 localStorage。不同浏览器、不同打开方式（file 或 http）、文件路径改变后可能使用不同的存储空间。请在“学习记录”中导出备份；清空浏览器数据前尤其如此。若存储不可用，手册会提示，并保留本次会话内的记录供导出。

本手册没有分析脚本、广告、网络请求或远程数据存储。实验在内存中运行；刷新页面会重置实验，不重置已保存的学习记录。
